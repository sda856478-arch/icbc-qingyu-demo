# 工银青誉计划 · 交互小样

面向大学生的荣誉档案与奖金到账周转服务原型，使用 HTML、CSS 和原生 JavaScript 构建，支持手机和电脑。

在线演示：[工银青誉计划小样](https://qingyu-plan-demo.astutesky1.chatgpt.site)。该链接使用原演示站点的访问权限，仓库保存源码，不会改变演示站点的访问范围。

## 已实现的演示操作

- 学生认证：确认示例身份和学籍资料，分别授权身份核验。
- 荣誉档案：按类别筛选，查看、添加、编辑和删除奖项、奖学金、论文及专利记录。
- 荣誉认证：区分已认证、核验中和未认证；提交示例认证申请。修改已认证记录后重新核验。
- 公开授权：默认关闭，可选择公开的荣誉范围；关闭后企业视角停止查询。
- 企业核验：凭档案标识码查询当前获授权内容，不展示银行金融信息。
- 奖金周转：仅展示已认证且尚未发放的个人奖金，校验申请金额不超过本人待发金额，并生成待银行独立审查的演示申请摘要。

## 本地运行

无需安装依赖、无需构建。下载仓库后直接打开 `dist/index.html`，或在仓库目录运行：

```bash
python -m http.server 8000 --directory dist
```

然后访问 <http://localhost:8000>。Windows 如使用 Python Launcher，也可将 `python` 换成 `py`。

## 文件结构

tests/

README.md
.gitignore

## 检查演示逻辑

安装 Node.js 后，在仓库目录运行：

```bash
node --check dist/app.js
node tests/check-demo.cjs
```

检查覆盖默认私密状态、授权范围、撤回授权、金额上限、认证状态转换、编辑后的重新核验、输入转义和学生认证门槛。检查通过 DOM 桩验证逻辑，不替代真实浏览器的视觉和兼容性测试。

## 数据与业务范围

这是项目交互原型，所有人物、荣誉、金额、机构确认和认证结果均为示例，不代表真实核验结论或金融报价。

- 状态仅保存在当前页面内存中，刷新或重置演示后恢复初始示例。
- 未连接工商银行、高校、征信、论文或专利系统。
- 不上传证明材料；文件选择只在本地显示文件名。
- 不向银行提交申请，不自动授信、不产生贷款或放款。
- 公开范围控制是演示逻辑。未来接入真实资料时，应在服务端实现身份认证、权限验证、数据隔离、日志审计和授权撤回。

本版本对应 2026 年 10 月 8 日制作的“工银青誉计划”交互小样。
